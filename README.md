Number Guessing Game

A simple CLI number guessing game built for fun and a little light coding practice. 

Overview
Interactive Gameplay:** Pick a range, guess the secret number, and get higher/lower hints.
Why Built:** Created purely for fun while sharpening basic programming concepts (loops, conditional logic, and error handling).

*Feel free to clone, tweak, or add new features like score tracking!*
